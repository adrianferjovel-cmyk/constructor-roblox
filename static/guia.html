Camino fácil Render — sin SSH ni claves

Recomendado para empezar hoy. Desventaja: se duerme a los 15 min sin uso (se despierta solo).

1
Sube tu proyecto a GitHub En github.com → New repository → nombre constructor-roblox → Public → Create. Luego Add file → Upload files y arrastra todo el proyecto (incluida la carpeta oculta .github) → Commit.
2
Crea tu cuenta en render.com Entra en render.com → Sign up → Login with GitHub (gratis, sin tarjeta).
3
Despliega con un clic En Render: New → Blueprint → elige tu repo constructor-roblox → Create. Render detecta render.yaml y lo construye solo (~2 min).
4
Copia tu URL y tu clave Cuando esté "Live", copia la URL (algo como https://constructor-roblox.onrender.com). Luego en Environment copia el valor de CLAVE_API.
5
Conecta Roblox En roblox/constructor_plugin.lua: URL_BASE = "https://tu-servicio.onrender.com" CLAVE_API = "tu-clave" Reinstala el plugin. Y en tu navegador abre la URL de Render → pega la clave en el campo del panel.
✅ Terminaste con Render. Ahora puedes pedir estructuras desde cualquier parte y hasta tu juego publicado podrá construir.

Camino Oracle VM 24/7 siempre encendida

Más potente y sin límite de horas, pero con más pasos. Úsalo si ya creaste la cuenta.

1
Crear la VM Compute → Instances → Create. Si VM.Standard.A1.Flex da "out of capacity", elige VM.Standard.E2.1.Micro (también gratis).
2
Guardar la clave SSH En "Add SSH keys" → Generate a key pair for me → Save Private Key (guarda el .pem en tu PC) → Create.
3
Abrir el puerto 8080 Networking → Virtual cloud networks → Security Lists → Add Ingress Rule: Source 0.0.0.0/0, TCP, puerto 8080.
4
Subir el proyecto a GitHub Igual que en el paso 1 de Render (repo constructor-roblox con todos los archivos).
5
Instalar en la VM En la consola de Oracle pulsa Cloud Shell (el icono de terminal), sube tu .pem y ejecuta: chmod 600 clave.pem ssh -i clave.pem ubuntu@TU_IP git clone https://github.com/TU_USUARIO/constructor-roblox.git cd constructor-roblox sudo bash oracle/instalar.sh Luego: sudo nano /etc/constructor-roblox.env → cambia la clave → Ctrl+O, Enter, Ctrl+X → sudo systemctl restart constructor-roblox
6
Activar el deploy automático En GitHub: Settings → Secrets → New secret ×3: ORACLE_HOST (tu IP), ORACLE_USER (ubuntu), ORACLE_SSH_KEY (todo el contenido del .pem). Luego Actions → Run workflow.
7
Conectar Roblox En el plugin: URL_BASE = "http://TU_IP:8080" CLAVE_API = "tu-clave" Reinstala el plugin y abre http://TU_IP:8080 en el navegador con tu clave.
